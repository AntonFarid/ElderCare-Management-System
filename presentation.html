The Care Gap: Hajj Ahmed's Story

Traditional Care Limitations

Hajj Ahmed is 80 years old. His vitals change hourly. Standard nursing systems rely on manual end-of-day logging, leaving critical alerts delayed by hours, with no real-time safety nets.

The Opportunity

By combining distributed system architecture with predictive and generative AI, we can monitor clinical trends dynamically, generate human-readable reports, and alert caregivers instantly.

The Solution: Sanad

Unified Multi-Role Portal

Dedicated user interfaces for Administrators, Team Leaders, Caregivers (Employees), and Family Members.

AI-Powered Decisions

Random Forest model predicting health risks and diet plans, combined with Google Gemini generating narratives.

SignalR Real-Time Alerts

Instantly sends critical alarms and clinical summaries to supervisors' browsers without page refreshes.

Frontend Architecture: React SPA & State Flow

UI & Styling Layer

Built with React 19 and Vite for fast development. Uses TailwindCSS 4 and HeroUI for beautiful glassmorphic components, and Framer Motion for micro-animations.

State & Data Cache

API integration powered by Axios. Server state caching, background refetching, and synchronization managed by TanStack React Query v5. Role-based client access using JWT tokens.

Analytics & Real-time

Subscribes to server-sent events via SignalR Client for push alerts. Dynamic visualizations of historical health metrics using interactive Recharts graphs.

Backend Architecture: ASP.NET 8 Core Engine

Clean Onion Layers

Enforces strict dependency inversion: API -> Infrastructure -> Application -> Domain. Database mapping is managed through Entity Framework Core with SQL Server.

Security & Identity

Secured via ASP.NET Core Identity, role claims-based JWT authentication, custom request rate limiting, and password hashing for protection.

Hubs & Integrations

Implements SignalR Hubs for real-time connection groups. Uses HttpClientFactory to coordinate API requests to Gemini AI and the FastAPI microservice.

ML Architecture: Predictive & Generative Brain

FastAPI Microservice

Python FastAPI web server for hosting predictive models. Strict endpoint schema validation and formatting powered by Pydantic v2 models.

Multi-Model Vitals Predictor

Trains and selects the highest-accuracy classifier (Random Forest, Gradient Boosting, Decision Trees, or Logistic Regression), backed by a simple Rule-Based Clinical Override safety net for critical vitals thresholds.

Dynamic Diet Recommendation

Predicts daily breakfast, lunch, and dinner suggestions using Random Forest models. Automatically filters out ingredients triggering active user allergies, restrictions, or medical conditions.

Generative Reporting

Constructs structured prompts sent to the Google Gemini API for automated, daily clinical summaries. Implements custom local fail-safe templates.

ML Vitals Pipeline: Preprocessing & Features

1. Dynamic Preprocessing

Maps and orders incoming parameters to match the exact feature columns structure expected by the trained model. Handles missing data using median imputer rules.

2. Outlier Clipping

Clips non-physical sensor outliers: heart rate to [30, 220], blood pressure to [50, 250], blood sugar to [20, 600], oxygen saturation to [20, 100], and pain level to [0, 10].

3. 15 Physiological Features

Feeds vital signs (BP, HR, BS, Temp, SpO2, RR) and behavioral indicators (age, sleep hours, missed meds, meals eaten, mood, water intake, pain level) into classifiers.

ML Vitals Pipeline: Model Selection & F1 Evaluation

4 Candidates Evaluated

Trains and tests four model types: Random Forest, Gradient Boosting, Decision Trees, and Logistic Regression.

F1-Score Optimization

Prioritizes detecting "High Risk" cases above all. Evaluates performance using F1-Score to optimize the trade-off between precision and recall, minimizing False Negatives to prevent missing any critical health crisis.

Prediction & Auditing

Returns classification (High/Low risk) and confidence probability score. Logs features, output, and timestamps to an auditing CSV file.

ML Vitals Pipeline: Override Safety Net

Hybrid Clinical Overrides

To guarantee patient safety, a deterministic rule layer overrides ML outputs for acute symptoms:

  • BP ≥ 160/100 or ≤ 85/50 mmHg
  • Oxygen Saturation (SpO2) ≤ 92%
  • Heart Rate ≥ 115 or ≤ 45 bpm
  • Blood Sugar ≥ 200 or ≤ 60 mg/dL
  • Missed Medication Doses ≥ 2
# FastAPI Rule Overrides
if data.systolic_bp >= 160 or data.diastolic_bp >= 100:
    is_high_risk = True
    confidence = 0.99  # Hypertensive Crisis
    
if data.oxygen_saturation <= 92:
    is_high_risk = True

    is_high_risk = True
    confidence = 0.99  # High Non-Adherence

Gemini AI: Structured Narrative Reports

1. Prompt Construction

Dynamic aggregation of caregiver observations, times, notes, and vitals. Constructed prompt strictly requires 6 sections: Summary, Medications, Meals, Activities, Observations, and Recommendations.

2. Fallback Template

Robust design: If Gemini API rate limits are breached or Internet is down, the system generates a template-based clinical report dynamically from raw database metrics.
